# Gaps (ranked)

1. Free-form selection and invert selection.
2. Scale / skew a selection with handles.
3. Text styling (bold, italic, underline) and a live text preview on the canvas.
4. Rulers.
5. More brush types (calligraphy, oil, crayon, marker, watercolour).
6. Layer thumbnails and blend modes.
7. Printing.
8. Pasting an image larger than the canvas should offer to enlarge the canvas (today it is clipped).
9. Colour emoji in text (egui draws emoji in one colour).
10. Code signing for Windows and notarization for macOS.
